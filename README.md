# Ecommerce Sales Analysis Using Excel

## 📊 Project Overview

This project focuses on analyzing ecommerce sales data using Microsoft Excel to identify sales trends, customer behavior, product performance, and key business insights.

The project demonstrates practical skills in:

* Data Cleaning
* Data Transformation
* Excel Analysis
* Pivot Tables
* Pivot Charts
* KPI Analysis
* Dashboard Development
* Business Insights
* Data Visualization

---

## 🎯 Business Objective

The objective of this project is to analyze ecommerce sales data and convert raw business data into meaningful insights that can support better decision-making.

The analysis focuses on understanding:

* Overall sales performance
* Product performance
* Customer purchasing behavior
* Sales trends
* Category-level performance
* Geographic performance
* Key business KPIs
* Areas of improvement and growth
